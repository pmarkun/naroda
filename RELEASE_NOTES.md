# Versão Teste — Primeira Rodada

**Versão:** `1.0.0-beta.1`
**Código:** 2
**Nome:** Primeira Rodada

## Novidades

- 123 perguntas em 4 categorias (Boas, Pra Roda, Poderosas, Especiais)
- Suporte a 3 idiomas: Português, English, Español
- Navegação por swipe ou toque nas laterais
- Compartilhe perguntas como imagem para stories
- Página "Como Jogar?" com instruções
- Funciona offline após a primeira carga
- Tela cheia via Trusted Web Activity (TWA)

## Testar

1. Instalar o APK no celular Android
2. Abrir o app — deve carregar `https://naroda.app.br/` em tela cheia
3. Testar: navegação, compartilhamento, troca de idioma, modo offline
